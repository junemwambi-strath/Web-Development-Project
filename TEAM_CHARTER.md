Summary about the app:
QuickFundi application is a localized services and worker verification platform designed to connect everyday households and clients across Kenya with trusted, skilled local blue-collar artisans - or fundis - such as plumbers, electricians, and handymen. Built specifically for clients looking to easily discover vetted service providers and for workers seeking a reliable digital space to showcase their specialties, the system enables users to seamless search verified artisan profiles, review transparent service rate estimates, and check past customer ratings before booking a local worker directly.

App Audit :
API Resources
Blue-collar workers’ personal profile (Name, Location, contact details, Description for clients )
Workers’ skill set profile (Job type, Experience, rate card, Availability, Reviews)
Booking details (Job type, location, date & time, worker chosen)
Client’s details (Name, phone number, location)

Actions users can take on the resources
For the workers:
 1. Create a profile with the necessary details.
 2. Add their skill set profile

For the clients:
 1. Find a worker in the system
 2. Book a worker
